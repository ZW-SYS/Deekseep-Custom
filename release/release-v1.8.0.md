# Deekseep 1.8.0 · 适配 DeepSeek 2.7.1

基于原作者 Lucian 的 [Deekseep](https://github.com/lllucccian/Deekseep) 二次创作，由张云安（ZW-SYS）移植与二开。GPL-3.0，免费开源。

- 包名：`com.dsmod.probe`　versionCode：`36`
- 目标宿主：DeepSeek 2.7.1（code287，大陆版）
- 文件：`Deekseep-1.8.0-unsigned-aligned.apk`（约 25MB，未签名，已 zipalign）
- SHA-256：`ea8426fe69c41f250fbd02bd6cf6a695816c537551afff3841502966299049e5`

## 新增 / 增强

- 适配 DeepSeek 2.7.1，重建 2.4.1 → 2.7.1 符号映射
- **Agent 半自动（默认）**：每步工具结果弹窗确认，点“发送”才发出
- **全自动回传**：默认关闭，须阅读风险提示并勾选同意才能开启；重要账号请勿开启
- **Agent 限速（全自动模式）**：两步间隔 ≥ 8 秒、每分钟 ≤ 5 步、每小时 ≤ 60 步，超出部分排队、不丢弃
- **门槛版防撤回**：灰色入口 + 安全警告 + 阅读同意后才可启用
- 原生侧栏多选：批量选择、删除、置顶
- Agent 剪贴板工具（默认关闭）
- 导出单条消息、字体大小调节
- 恢复：主题色、欢迎页鲸鱼动画、原生会话导航、本地会话目录合并、模型文件卡片、“数据用于优化体验”开关、更新弹窗拦截
- 公告、彩蛋、原作者致谢；移除捐赠入口

## 真机测试修复

- 设置首页空白（移植时误删分类卡片）
- Agent 工具结果“未能回传”（2.7.1 发送接口变为 7 参数）
- 桌面入口无图标
- 图片导入（背景 / 头像 / 贴纸）：增加备用读取方式，失败时显示具体原因，并自动换用另一种图片选择器

## 已知问题

- **Shizuku** 授权后仍可能显示“连接失败”，排查中
- 部分免 root 虚拟机（如 FPA）里导入图片可能报 `ENOENT`（虚拟机存储重定向），可再点一次“选择图片”改从“文件”中选取

## 底线关闭 / 未移植

- **底线关闭**：密码登录捕获、风控绕过与防封、设备 ID / OAID 伪装、登录与地区解锁、Agent 伪装
- **官方淘汰**：专家模式 / 额度解锁（2.7.1 已将三个模式合一）
- **未移植**：远程功能开关、附件引导提示、心跳 JSON Patch 分发器
