# YunSeek 界面 vs Nexus 1.7.6 对照（依据用户 2026-10-30 发的 Nexus 截图 + 2026-10-31 YunSeek 截图）
| 方面 | Nexus | YunSeek 1.8.1 | 改法 |
|---|---|---|---|
| 页面标题 | 左上大号粗体（“Nexus”“账号与隐私”“工程”），滚动收起 | 小号标题栏文字 | 大标题+收起 |
| 激活卡 | 纯蓝实色、白字、右侧大号半透明对勾 | 紫粉/红粉渐变、Y 字母头像、三角警告 | 纯色（激活蓝/未激活灰或浅红）+ 水印图标 |
| 图标 | 单色黑色线性图标，无底 | 彩色圆形底色小图标 | 单色线性 |
| 分组 | “功能”“帮助”小灰字分组，白色圆角卡，无分割线 | 一张长卡+分割线 | 分组卡 |
| 行 | 粗标题+灰色两行描述，开关蓝色 | 细标题、描述小且不统一 | 统一行样式 |
| 底栏 | 悬浮胶囊、选中项胶囊高亮 | 贴底平铺 | 悬浮胶囊 |
| 动画 | 安静：大标题收起、轻滑页面 | 7s 漂移渐变、1.8s 脉冲、0.4 弹跳缩放、多种方向混用 | 全删，只留一种页面滑动+按压缩放 |
| 杂项 | — | 悬浮“⋮”按钮压住内容 | 移入右上角 |
**用户定调（2026-11-01 09:40）：就要 Nexus 那种纯白底 + 单一蓝色强调色的简洁感。** 全局只用白/浅灰底、黑灰文字、一种蓝色；不要渐变、不要多彩色。
