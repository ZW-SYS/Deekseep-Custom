# 常见问题

原版排障说明存档于 [upstream/TROUBLESHOOTING_upstream.md](upstream/TROUBLESHOOTING_upstream.md)。

**安装失败 / 签名不一致**
先卸载之前装的任何版本（包括原作者签名版），再安装你自己签名的 APK。

**模块没生效**
确认 DeepSeek 版本是 2.7.1（code287）、作用域勾选了 `com.deepseek.chat`，然后强制停止 DeepSeek 再打开。

**设置首页空白**
1.8.0 已修复。仍然空白请确认装的是最新版本。

**Agent 工具执行了但结果没发出去**
默认是半自动模式：每步结果会弹窗，需要点“发送”。点了“稍后”的结果可以在 Agent 运行记录里重试。

**用 Agent 后账号被强制下线 / 要求重新验证**
这是 DeepSeek 2.4.1 起服务端的行为，模块不做任何规避。请保持半自动模式，不要在重要账号上开启全自动回传。

**导入背景 / 头像提示“无法读取所选图片（…ENOENT…）”**
多见于免 root 虚拟机（如 FPA）的存储重定向。再点一次“选择图片”会换另一种选择器，尽量从“文件”里选，不要直接走相册。

**Shizuku 显示“连接失败”**
已知问题，排查中。提 Issue 时请附上“连接失败：”后面的完整内容和模块日志。

**某个功能导致 DeepSeek 闪退**
关闭该功能，提 Issue 时附上模块崩溃记录和 DeepSeek 准确版本。

提交 Issue 时请不要贴账号凭据、Token、私人对话或未脱敏的设备信息。
