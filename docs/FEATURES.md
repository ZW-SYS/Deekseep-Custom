# 功能范围（1.8.0 移植版）

完整列表见 [README](../README.md#核心特性)，版本变化见 [CHANGELOG](../CHANGELOG.md)。原版功能说明存档于 [upstream/FEATURES_upstream.md](upstream/FEATURES_upstream.md)。

## 在 DeepSeek 2.7.1 上可用

- 提示词库、会话置顶、原生侧栏多选（批量删除 / 置顶）
- 会话导出与搜索、导出单条消息、字体大小
- 主题色、欢迎语、欢迎页鲸鱼动画、聊天背景 / 头像 / 贴纸
- 自定义系统提示词注入
- Agent：半自动（默认）/ 全自动（默认关闭，需风险同意）、限速、剪贴板工具（默认关闭）
- 门槛版防撤回（默认灰色，需阅读警告并同意）
- “数据用于优化体验”开关、更新弹窗拦截

## 底线关闭（不会移植）

额度 / 专家解锁、风控绕过与防封、设备标识伪装、登录与地区解锁、Agent 伪装、密码登录捕获。

## 未移植

远程功能开关、附件引导提示、心跳 JSON Patch 分发器、Local API 与隧道。
