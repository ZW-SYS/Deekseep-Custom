# 功能范围（YunSeek 1.8.1.1）

完整说明见 [README](../README.md)，版本变化见 [CHANGELOG](../CHANGELOG.md)。原版功能说明存档于 [upstream/FEATURES_upstream.md](upstream/FEATURES_upstream.md)。

## 支持的宿主

国内版 DeepSeek 2.7.1（287）、国内版 2.7.2（289）、国际 / Google Play 版 2.7.2（290），一个 APK 自动识别。2.7.3 尚未适配。

## 在 2.7.x 上可用

- **界面**：白底单蓝主题、字体大小、自定义字体、主题色、欢迎语、欢迎页鲸鱼动画、聊天背景 / 头像 / 贴纸、纯黑模式、液态玻璃输入框（默认关）、模型显示名（默认关）、界面导航管理器
- **聊天**：提示词库、自定义系统提示词注入、会话置顶、原生侧栏多选（批量删除 / 置顶）、快捷复制（纯文本 / 提取代码）
- **会话工具**：会话导出与搜索、导出单条消息、隐藏对话（原生侧栏同步隐藏）、沉浸阅读
- **草稿**：自动保存与恢复（默认开，纯本地）
- **隐私**：应用锁、后台防窥、防截屏
- **Agent**：半自动（默认）/ 全自动（默认关闭，需风险同意）、限速、剪贴板工具（默认关闭）
- **AI 心跳**（实验性，默认关）：限速 15 分钟一次、每天最多 12 次
- 门槛版防撤回（默认灰色，需阅读警告并同意）
- “数据用于优化体验”开关、更新弹窗拦截
- 数据中心：ZIP / JSON 导入导出

## 2.7.x 上不提供

- 思考链代码块复制（Compose 界面暂时无法可靠注入）

## 底线关闭（不会做）

额度 / 专家解锁、风控绕过与防封、设备标识伪装、登录与地区解锁、Agent 伪装、密码登录捕获。

## 未移植

远程功能开关、附件引导提示、心跳 JSON Patch 分发器、Local API 与隧道。
